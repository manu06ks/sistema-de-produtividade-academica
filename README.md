# Unistudy - Ecossistema Integrado de Produtividade Acadêmica

O **Unistudy** é uma solução definitiva desenvolvida para mitigar a sobrecarga mental acadêmica. Através de uma plataforma web minimalista, o ecossistema integra gestão de tarefas, armazenamento e tempo focado em um único lugar.

---

##  O Problema: O Caos Digital
A plataforma nasceu para combater os desafios enfrentados por estudantes no ambiente digital:
* **Fragmentação Exaustiva:** Perda de horas alternando entre ferramentas como WhatsApp, Google Drive e Trello.
* **Custo de Contexto:** Esforço mental 
desperdiçado na alternância de ferramentas que quebra a concentração.
* **Invisibilidade do Esforço:** Dificuldade em mensurar o real tempo dedicado aos estudos extraclasse.
##   Funcionalidades Principais
* ** Autenticação:** Sistema de login e cadastro com criptografia Bcrypt e proteção via tokens JWT.
* ** Planner Kanban:** Gestão visual *Drag and Drop* para organizar tarefas e provas por disciplina.
* ** Biblioteca:** Upload direto e centralização de documentos (PDFs e imagens) vinculados às matérias.
* ** Smart Timer:** Cronômetro nativo para gerenciamento de ciclos de foco profundo e pausas.

---

##  Stack Tecnológica

### Frontend
* **React.js:** Para renderização dinâmica (SPA).
* **Tailwind CSS:** Design responsivo, minimalista e focado em usabilidade.

### Backend & Banco de Dados
* **Node.js + Express:** Construção da API e middlewares de segurança.
* **PostgreSQL:** Persistência de dados sólida em banco relacional.
* **Multer:** Gerenciamento do sistema de arquivos para uploads.
